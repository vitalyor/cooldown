# Идеи на будущее

Не в работе. Записано, чтобы сделать позже.

## 1. Хуки Codex и Claude Code
Досконально изучить, что умеют хуки, и сделать свои хуки Cooldown. Только полезное и быстрое, ничего, что тормозит агентов.
- Изучить: события (SessionStart, UserPromptSubmit, Pre/PostToolUse, PermissionRequest, Stop, SubagentStart/Stop, Interrupt, SessionEnd), что приходит на вход, тайм-ауты, одобрение хуков в Codex (trusted_hash в config.toml), соседство с Coucou в ~/.codex/hooks.json и ~/.claude/settings.json.
- Возможная польза: мгновенное «закончил» вместо опроса файлов; «ждёт вашего ответа» (PermissionRequest); точное «сейчас работает» для индикатора в строке меню; учёт времени работы по проектам.
- Принципы: хук только пишет короткое событие и сразу выходит (миллисекунды); не мешать Coucou; включается в настройках; файловый наблюдатель остаётся запасным.

## 2. Индикатор активности агента в строке меню
Видеть, что какая-то сессия сейчас работает. Аккуратно и информативно, без большой точки.
Наброски:
- Значок Codex или Claude едва заметно «дышит» (плавная прозрачность), пока агент работает.
- Тонкий бегущий блик по полоске лимита работающего агента.
- Маленькое число рядом со значком, если работают несколько сессий.
- Короткая вспышка, когда работа закончена, или «ждёт ответа» в другом цвете.
- Без анимации при «Уменьшить движение»; по наведению — подсказка: какие чаты работают.

## 3. Годовая карта активности, как на GitHub
Сетка «день × неделя» за год, цвет клетки по тому, сколько работали агенты. Можно отдельной вкладкой.
- Мера дня на выбор: токены, стоимость по API, время работы агентов, число завершённых задач.
- Переключатель Codex / Claude / оба; оттенок в цвете агента.
- Наведение на клетку: дата, токены, ≈$, проекты дня. Нажатие: открыть статистику этого дня.
- Под сеткой: серия дней подряд, самый активный день недели, итог за год.
- Важно: сейчас история хранится 45 дней. Нужно хранить дневные итоги отдельно и бессрочно (это крошечные данные), а при первом запуске собрать прошлое из файлов Codex и Claude Code, сколько их осталось на диске.
