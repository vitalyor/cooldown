The first public release. **English** · [Русский](#русский)

Cooldown lives in the macOS menu bar and keeps an eye on Codex and Claude: limits at a glance, what each
agent is doing, a card when work is done, and continuing after a limit resets. Everything runs locally.
The interface is in Russian for now.

### Highlights
- Codex and Claude limits in the menu bar, with forecast, daily budget and comparison with past weeks.
- Live activity: a soft light on a working agent's bar, an orange dot when it waits for you.
- Cards: finished (with the start of the answer, time and share of the limit), waiting for your decision,
  limit is back, silent for 15 minutes, stopped with an error.
- Continue after a reset: Codex tasks and Claude Code sessions by themselves, Claude Desktop chats with one press.
- Statistics: tokens, projects, models, API-price estimate, a GitHub-style year of work, CSV export.
- Optional hooks for Codex and Claude Code for instant events.

### Install
1. Download **Cooldown-1.0.0.dmg**, open it and drag Cooldown to Applications.
2. Open Cooldown. macOS will say it cannot verify the developer — the app is not notarized by Apple.
   Open **System Settings → Privacy & Security**, scroll down and press **Open Anyway**.
   (Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Cooldown.app`.)
3. Cooldown shows what else it needs under Settings → Readiness (notifications, Accessibility).

Requires macOS 26 or later. Codex auto-continue uses Python 3 (comes with the Command Line Tools).

### Checksums
`SHA256SUMS.txt` is attached: `shasum -a 256 -c SHA256SUMS.txt`.

### Русский

Первый публичный выпуск. Cooldown живёт в строке меню macOS и следит за Codex и Claude: лимиты одним
взглядом, что делает каждый агент, карточка, когда работа готова, и продолжение после сброса лимита.
Всё работает локально.

**Главное**
- Лимиты Codex и Claude в строке меню, прогноз, бюджет на день и сравнение с прошлыми неделями.
- Активность: мягкий свет на линии работающего агента, оранжевая точка — ждёт вас.
- Карточки: закончил (с началом ответа, временем и долей лимита), ждёт решения, лимит восстановился,
  молчит 15 минут, остановился с ошибкой.
- Продолжение после сброса: задачи Codex и сессии Claude Code сами, чаты Claude Desktop — одним нажатием.
- Статистика: токены, проекты, модели, примерная цена по API, «Год работы», выгрузка в CSV.
- Хуки для Codex и Claude Code (по желанию) — мгновенные события.

**Установка**
1. Скачайте **Cooldown-1.0.0.dmg**, откройте и перетащите Cooldown в «Программы».
2. Откройте Cooldown. macOS скажет, что не может проверить разработчика — приложение не заверено Apple.
   Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите
   **Всё равно открыть**. (Или в Терминале: `xattr -dr com.apple.quarantine /Applications/Cooldown.app`.)
3. Чего ещё не хватает, Cooldown покажет в «Настройки → Готовность» (уведомления, Универсальный доступ).

Нужна macOS 26 или новее. Автопродолжение Codex использует Python 3 (есть в Command Line Tools).
