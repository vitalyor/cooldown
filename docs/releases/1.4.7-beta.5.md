**Beta.** A preview for testing; it reaches only Macs with Settings → Updates → Beta versions turned on.

### Fixed
- **VPN guard screen says the real reason.** A pause is now "goes through <country> — bypassing the VPN", "address … is blocked in the guard settings" or "can't be checked", on the screen and on the banner over the limits; the bad address is the one shown.
- **No network is not an alarm.** Offline, the screen and the header say "No network — the agents will wait" instead of a red, pulsing pause.
- **"Route is fine" only when it is.** While one agent is still being checked after a network change, the screen says "Checking the route…".
- **Guard switched off while its screen is open:** it says so and hides its buttons, instead of "Checking…" forever.
- **A new address shared by Claude and Codex** is one line; server names are each agent's own; the time zone note goes when nothing is guarded.
- **The shield in the header:** its checkmark sits inside the button and no longer gets cut or leaves a mark when pressed.
- **Old Claude limits are never taken for fresh ones,** even when Claude Code does not redraw its screen.
- **The Terminal steps for Claude Code** ("Open in Terminal", "Sign in with subscription") say "done" only when every step worked, and "that didn't work" otherwise.
- **Phone messages after a second outage** keep their real age, so an hours-old alert stays quiet.
- Claude Code without a sign-in is recognised in a second, not after 25.

### Русский

**Бета.** Предварительная версия для проверки; её получают только Mac с включёнными «Настройки → Обновления → Бета-версии».

**Исправлено**
- **Экран защиты VPN называет настоящую причину.** Пауза теперь — «идёт через <страну> — мимо VPN», «адрес … запрещён в настройках защиты» или «не удаётся проверить», и на экране, и на баннере над лимитами; показан именно плохой адрес.
- **Нет сети — не тревога.** Без сети экран и шапка пишут «Нет сети — агенты подождут», а не красную пульсирующую паузу.
- **«Маршрут в порядке» — только когда это так.** Пока один агент ещё проверяется после смены сети, экран пишет «Проверяю маршрут…».
- **Защиту выключили при открытом экране:** он так и говорит и прячет кнопки, а не висит на «Проверяю…».
- **Новый адрес, общий для Claude и Codex,** — одна строка; имена серверов у каждого агента свои; заметка о часовом поясе уходит, когда ничего не защищено.
- **Щит в шапке:** галочка внутри кнопки, не обрезается и не оставляет след при нажатии.
- **Старые лимиты Claude никогда не принимаются за свежие,** даже если Claude Code не перерисовал экран.
- **Шаги в Терминале для Claude Code** («Открыть в Терминале», «Войти через подписку») пишут «Готово», только если всё прошло, иначе — «Не получилось».
- **Сообщения на телефон после второго обрыва** сохраняют свой настоящий возраст: многочасовая тревога остаётся тихой.
- Claude Code без входа в аккаунт распознаётся за секунду, а не за 25.
