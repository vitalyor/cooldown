### Fixed
- **Legible on clear glass.** With Liquid Glass set to its clearest (macOS 27's transparency slider), text in the window and on cards could vanish over light content. A soft veil in the appearance's own tone now sits between the glass and the content; it follows the slider (the clearer the glass, the denser the veil) and Reduce Transparency / Increase Contrast. The glass and its blur stay.
- **The safe restart of Claude checks for unsent text again.** Since 1.4.0 it could quit Claude Desktop while a draft was in the message field.
- **"Access to data blocked" after updating to macOS 27.** Claude Code, which Cooldown runs to read limits, looks into Chrome's and other browsers' folders for its extension at start, and macOS blamed Cooldown. Cooldown now runs it without that check.
- Built with the macOS 27 SDK without a single warning.

### Install
`brew install --cask vitalyor/tap/cooldown`, or download **Cooldown-1.4.4.dmg** and drag it to Applications.
On an earlier version? Cooldown updates itself (Settings → Updates).

### Русский

**Исправлено**
- **Читается на прозрачном стекле.** Если стекло Liquid Glass выкручено на максимум прозрачности (ползунок в macOS 27), текст в окне и на карточках мог теряться над светлым содержимым. Теперь между стеклом и содержимым лежит мягкая вуаль в тон оформления. Она следит за ползунком (чем прозрачнее стекло, тем плотнее вуаль) и за «Уменьшить прозрачность» и «Увеличить контраст». Стекло и размытие остаются.
- **Безопасный перезапуск Claude снова проверяет неотправленный текст.** С 1.4.0 он мог закрыть Claude Desktop, пока в поле ввода лежал черновик.
- **«Доступ к данным заблокирован» после обновления до macOS 27.** Claude Code, который Cooldown запускает для чтения лимитов, при старте заглядывает в папки Chrome и других браузеров в поисках своего расширения, и macOS записывала это на Cooldown. Теперь Cooldown запускает его без этой проверки.
- Собрано на SDK macOS 27 без единого предупреждения.

**Установка**
`brew install --cask vitalyor/tap/cooldown` или скачайте **Cooldown-1.4.4.dmg** и перетащите в «Программы».
Стоит более ранняя версия? Cooldown обновится сам («Настройки → Обновления»).
