**English** · [Русский](#русский)

### What's new
- **Codex auto-continue, rebuilt.** A new engine with the same promise: one message per stopped task, only after a fresh check that the limit is really back, never an approval on your behalf. Clearer statuses explain what it is waiting for, and if it can't confirm a message arrived, it never sends to that conversation again by itself.
- **Signed by Apple's Developer ID from the next version.** This release teaches the updater to accept it; 1.3.1 follows right away, notarized by Apple, so Cooldown opens without the "unverified developer" warning.

### Fixes
- Cards for Claude Desktop answers quote the right answer again (the app moved where it shows the text).
- The "limit resets in 10 minutes" card hides by itself.

### Install
New here? `brew install --cask vitalyor/tap/cooldown`, or download **Cooldown-1.3.0.dmg** and see the [install steps](https://github.com/vitalyor/cooldown#install).
Already using Cooldown? It updates itself (Settings → Updates).

### Русский

**Что нового**
- **Автопродолжение Codex переписано.** Новый механизм с тем же обещанием: одно сообщение на остановленную задачу, только после свежей проверки, что лимит действительно вернулся, и никаких одобрений за вас. Статусы понятнее объясняют, чего он ждёт, а если не удалось подтвердить, что сообщение дошло, в этот диалог он больше сам не отправит.
- **Со следующей версии — подпись Apple Developer ID.** Этот выпуск учит обновление её принимать; сразу за ним выйдет 1.3.1, заверенная Apple, — Cooldown будет открываться без предупреждения о «непроверенном разработчике».

**Исправления**
- Карточки об ответах Claude Desktop снова цитируют нужный ответ (приложение перенесло, где показывает текст).
- Карточка «лимит сбросится через 10 минут» скрывается сама.

**Установка**
Впервые? `brew install --cask vitalyor/tap/cooldown` или скачайте **Cooldown-1.3.0.dmg** и следуйте [инструкции](https://github.com/vitalyor/cooldown/blob/main/README.ru.md#установка).
Уже пользуетесь? Cooldown обновится сам («Настройки → Обновления»).
