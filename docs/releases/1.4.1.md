**English** · [Русский](#русский)

### Fixed
- With Antigravity installed, the Codex, Claude and Antigravity switch no longer breaks names across two lines: it takes all the room beside the buttons and keeps every name on one line.

### Install
`brew install --cask vitalyor/tap/cooldown`, or download **Cooldown-1.4.1.dmg** and drag it to Applications.
On 1.4.0 or 1.3.x? Cooldown updates itself (Settings → Updates).

### Русский

**Исправлено**
- Если установлен Antigravity, переключатель Codex, Claude и Antigravity больше не переносит названия на вторую строку: он занимает всё место рядом с кнопками, и каждое название помещается в одну строку.

**Установка**
`brew install --cask vitalyor/tap/cooldown` или скачайте **Cooldown-1.4.1.dmg** и перетащите в «Программы».
Стоит 1.4.0 или 1.3.x? Cooldown обновится сам («Настройки → Обновления»).
