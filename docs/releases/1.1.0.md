### What's new
- **Answer your agents from a card.** When Codex, Claude Code or a Claude Desktop chat asks for permission or asks a question while you are in another app, a card shows exactly what it wants — the command, the files, the question — with the answers right on it: Allow, Allow for the session, Decline, or open the chat. Only the button you press is sent, and only if the very same request is still waiting.
- **Codex auto-continue is built in.** No Python and no separate tool any more: Cooldown watches the tasks you chose itself, wakes exactly when the limit resets and continues the task once. Your existing watches and history move over by themselves.
- **Settings in their own window**, laid out like System Settings: categories with search, a live preview of the menu bar icon, release notes in Updates.
- **Update modes:** don't check, download only (install with one press), or download and install by itself.
- **Hover the week.** Point at the inner ring (or the week line) and the big number shows the week.

### Fixes
- Claude limits could lag by an hour: Claude Code's `/usage` showed its cached numbers. Cooldown now waits for the fresh ones, retries a failed read within a minute and re-reads shortly after Claude answers.
- After a limit reset the old, higher figure no longer sticks.

### Install
New here? Download **Cooldown-1.1.0.dmg** and see the [install steps](https://github.com/vitalyor/cooldown#install).
On 1.0.1? Cooldown updates itself (Settings → Updates).

### Русский

**Что нового**
- **Ответ агентам прямо с карточки.** Когда Codex, Claude Code или чат Claude Desktop просит разрешение или задаёт вопрос, а вы в другом приложении, приходит карточка с тем, что именно он хочет — команда, файлы, вопрос — и с ответами на ней: «Разрешить», «На всю сессию», «Отклонить» или открыть чат. Уходит только нажатая вами кнопка и только если тот же самый запрос ещё ждёт.
- **Автопродолжение Codex встроено.** Без Python и отдельной программы: Cooldown сам следит за выбранными задачами, просыпается точно в момент сброса лимита и продолжает задачу один раз. Прежние наблюдения и история переносятся сами.
- **Настройки в отдельном окне**, как системные: категории с поиском, живой предпросмотр значка, «Что нового» в разделе обновлений.
- **Режимы обновлений:** не проверять, только скачивать (установка одним нажатием) или скачивать и ставить самому.
- **Неделя при наведении.** Наведите на внутреннее кольцо (или строку «Неделя») — большое число покажет неделю.

**Исправления**
- Лимиты Claude могли отставать на час: `/usage` в Claude Code показывал сохранённые цифры. Теперь Cooldown дожидается свежих, при сбое повторяет через минуту и перечитывает вскоре после ответа Claude.
- После сброса лимита старая, бо́льшая цифра больше не залипает.

**Установка**
Впервые? Скачайте **Cooldown-1.1.0.dmg** и следуйте [инструкции](https://github.com/vitalyor/cooldown/blob/main/README.ru.md#установка).
Стоит 1.0.1? Cooldown обновится сам («Настройки → Обновления»).
