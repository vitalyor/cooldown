**Beta.** A preview for testing; it reaches only Macs with Settings → Updates → Beta versions turned on.

### New
- **Beta versions.** Settings → Updates → Beta versions: new things before everyone else. Betas are prereleases on GitHub, signed and notarized like any release; Homebrew and Cooldowns with the switch off never get them. Turn it off and the next update is a regular version.

### Fixed
- **Exit addresses in the VPN guard.** One address used by several services showed up as several rows, all named after Claude. Now it is one row listing every service that goes out through it; a name given to it counts for all of them. The name field no longer breaks over three lines.

### Русский

**Бета.** Предварительная версия для проверки; её получают только Mac с включёнными «Настройки → Обновления → Бета-версии».

**Новое**
- **Бета-версии.** «Настройки → Обновления → Бета-версии»: новое раньше всех. Беты выходят на GitHub как предварительные, подписаны и нотаризованы как обычные версии; Homebrew и Cooldown с выключенным переключателем их не получают. Если выключить, следующей придёт обычная версия.

**Исправлено**
- **Адреса выхода в защите VPN.** Один адрес, через который выходят несколько сервисов, показывался несколькими строками, и все подписаны «Claude». Теперь это одна строка со всеми сервисами; имя адреса действует для всех. Поле имени больше не разваливается на три строки.
