**Beta.** A preview for testing; it reaches only Macs with Settings → Updates → Beta versions turned on.

### Changed
- **Setup no longer says you need both Claude Code and Codex.** It now says that Cooldown shows limits for
  the agents you use, that Claude limits need Claude Code even if you chat in Claude Desktop, and that an
  agent you don't use can be skipped.

### Русский

**Бета.** Предварительная версия для проверки; её получают только Mac с включёнными «Настройки → Обновления → Бета-версии».

**Изменено**
- **Настройка больше не говорит, что нужны и Claude Code, и Codex.** Теперь там сказано, что Cooldown
  показывает лимиты тех агентов, которыми вы пользуетесь, что для лимитов Claude нужен Claude Code, даже если
  вы пишете в Claude Desktop, и что ненужного агента можно пропустить.
