### What's new
- **Updates from GitHub.** Cooldown checks the releases every few hours and installs a new version by
  itself when the Mac is idle for a moment (or by one press — see Settings → Updates). Before installing,
  it checks the checksum and that the new version is signed by the same certificate.
- **No more false "Codex is waiting for you" cards.** With "approve for me", Codex asks for permission
  for every command and its own reviewer answers in seconds. Cooldown now waits 20 seconds and shows the
  card only if nobody answered.

### Install
New here? Download **Cooldown-1.0.1.dmg** and see the [install steps](https://github.com/vitalyor/cooldown#install).
Already on 1.0.0? Download this one by hand once: 1.0.0 cannot update itself yet.

### Русский

**Что нового**
- **Обновления с GitHub.** Cooldown раз в несколько часов смотрит релизы и сам ставит новую версию,
  когда Mac ненадолго без дела (или по одному нажатию — «Настройки → Обновления»). Перед установкой
  проверяет контрольную сумму и что версия подписана тем же сертификатом.
- **Больше никаких ложных «Codex ждёт вашего решения».** С «Подтверждать за меня» Codex спрашивает
  разрешение на каждую команду, а его собственный проверяющий отвечает за секунды. Теперь Cooldown ждёт
  20 секунд и показывает карточку, только если ответа так и не было.

**Установка**
Впервые? Скачайте **Cooldown-1.0.1.dmg** и следуйте [инструкции](https://github.com/vitalyor/cooldown/blob/main/README.ru.md#установка).
Уже стоит 1.0.0? Один раз скачайте эту версию вручную: 1.0.0 обновляться само ещё не умеет.
