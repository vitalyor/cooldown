### What's new
- **VPN guard** (Settings → VPN guard, off until you turn it on). AI services ban accounts used from countries they don't serve, and a VPN drops now and then. Cooldown asks Anthropic and OpenAI themselves which country your requests reach them from — along the same route the agents use, so it works whether the VPN runs on the Mac or on the router, over IPv4 and IPv6 apart, and through a system proxy (Clash, V2Ray) if you use one. The check is anonymous (no account, no cookies) and needs no server of ours.
  - While a route is wrong, Claude Code and Codex don't send your messages (their hooks hold them), Claude Code also stops between steps, and Cooldown makes no requests of its own to that service.
  - Claude Desktop, ChatGPT and Antigravity can be paused by the system: nothing is closed or lost, and they go on where they stopped when the VPN is back. If Cooldown itself stops, they are released within two seconds.
  - One card says which service sees which country, a push reaches your iPhone once, and "VPN is back" when it is.
  - When the router switches to another server, work goes on and a card asks whether to allow the new address; you can name your exits ("US-1").

### Good to know
- Not covered yet: claude.ai and chatgpt.com in a browser, and Claude Code started in Terminal while the VPN is already down (it signs in before any hook runs). A system network filter that closes these is planned.
- Codex runs a new hook only after you approve it in `/hooks`.

### Install
`brew install --cask vitalyor/tap/cooldown`, or download **Cooldown-1.4.3.dmg** and drag it to Applications.
On an earlier version? Cooldown updates itself (Settings → Updates).

### Русский

**Что нового**
- **Защита VPN** («Настройки → Защита VPN», выключена, пока вы её не включите). Сервисы ИИ блокируют аккаунты, которыми пользуются из неподдерживаемых стран, а VPN время от времени отваливается. Cooldown спрашивает сами Anthropic и OpenAI, из какой страны к ним приходят ваши запросы, — по тому же пути, что и запросы агентов, поэтому неважно, где включён VPN: на Mac или на роутере. IPv4 и IPv6 проверяются отдельно, а с системным прокси (Clash, V2Ray) — и маршрут через него. Проверка анонимная (без аккаунта и cookies), своего сервера не нужно.
  - Пока маршрут неправильный, Claude Code и Codex не отправляют ваши сообщения (их держат хуки), Claude Code ещё и останавливается между шагами, а сам Cooldown не обращается к этому сервису.
  - Claude Desktop, ChatGPT и Antigravity можно ставить на системную паузу: ничего не закрывается и не теряется, а когда VPN вернётся, работа продолжится с того же места. Если сам Cooldown остановится, пауза снимется за две секунды.
  - Одна карточка говорит, какой сервис видит какую страну, push на iPhone приходит один раз, а когда всё наладится — «VPN снова работает».
  - Если роутер переключился на другой сервер, работа не останавливается, а карточка спрашивает, разрешить ли новый адрес; адресам можно дать имена («США-1»).

**Стоит знать**
- Пока не закрыто: claude.ai и chatgpt.com в браузере и Claude Code, запущенный в Терминале, когда VPN уже не работает (он входит в аккаунт раньше любого хука). Это закроет системный сетевой фильтр, он в планах.
- Codex запускает новый хук только после одобрения в `/hooks`.

**Установка**
`brew install --cask vitalyor/tap/cooldown` или скачайте **Cooldown-1.4.3.dmg** и перетащите в «Программы».
Стоит более ранняя версия? Cooldown обновится сам («Настройки → Обновления»).
