Everything from the 1.4.6 betas, for everyone.

### VPN guard
- **A VPN blink is caught the moment it happens.** Cooldown listens to the system's routing messages and proxy settings: a tunnel that drops for a split second, a new Wi-Fi or a proxy switched on or off is seen at once, and the agents' apps pause until the route is checked again (usually under a second).
- **Sleep and wake.** On waking the apps pause first and go on after the first check, once the VPN is back.
- **Two addresses per service** (`api.anthropic.com` and `claude.ai`, `chatgpt.com` and `api.openai.com`); the worst one counts, so per-site VPN rules are caught.
- **Antigravity has a hook too** (`~/.gemini/config/hooks.json`, other entries kept): while the route to Google is wrong, a turn ends with a message instead of reaching the model.
- **The guard per agent:** each agent has its own switch in Settings → VPN guard; a switched-off agent is not checked, not paused, and its hook lets everything through.
- **Agents in Terminal (optional):** Claude Code, Codex and Antigravity CLI in a terminal pause too, even mid-answer, and go on where they were.
- **Time zone:** when the Mac's time zone gives the VPN away, Settings offers "Set time zone …" and "Restore my time zone" (macOS asks for an administrator password). The card about it is shown once per country and can be put off for an hour or a day, or turned off in Settings.
- Faster back to work (checks every 5 s for the first minute while a route is wrong), no automatic update while the guard holds something, a pause by hand lasts its hour even if Cooldown is closed, hook checks run in parallel (3 s at most).

### Limits
- **Claude limits are read reliably with newer Claude Code.** Claude Code 2.1.30x shows its last numbers first and "Refreshing…" until the server answers; on a slow connection Cooldown gave up too early and showed "Couldn't read the /usage screen", sometimes every time. It now waits for the answer (up to 15 s) and, if none comes, says it will try again in a minute.
- With the weekly limit spent, "back to work" names the weekly reset; the spent state no longer flips; numbers no longer jump back to an older reading; one Claude window is no longer counted twice in statistics; the history is no longer rewritten every minute.
- A hung Codex or Antigravity read no longer stops that agent's refreshes; the menu bar shows a dash instead of hours-old numbers.

### Agents and cards
- Auto-continue of Claude no longer loops while the weekly limit is spent and continues the chat the limit actually stopped.
- An answer to a Codex question is never sent twice; Cooldown's hooks in Codex no longer cost other tools' hooks their trust; only the newest three settings backups are kept.
- Cards answered in the agent's own window no longer pop up later; cards follow quiet hours; no extra sound on every card.
- **From the phone:** "Check now" and "Turn back on" on guard cards, "Remind me later" on the time zone card, "Update" on a new-version card (Face ID); typed answers need Face ID; an answer always lands on the question it was given for.

### Settings
- **Beta versions** (Settings → Updates): new things before everyone else. Off by default.
- **Report for the developer** (Settings → Diagnostics → Save…): one text file with the checks, tool versions, settings, limits and recent logs, with chat names, IP addresses, e-mail and the user name taken out. Nothing is sent: you send it yourself if something does not work.
- An Antigravity page; "What's new" shows formatted text in the app's language; sample cards can be stopped; exit addresses in the VPN guard are one row per address; setup no longer says you need both Claude Code and Codex.

### Reliability (a full review before this release)
- **Claude limits:** a first run ("Loading usage data…"), a slow link (up to 40 s), Pro with an idle session, a reset in the next year and Claude Code's "rate limited" are all read right; numbers Claude Code could not refresh are no longer taken for fresh ones; your MCP servers are not started for each reading; an npm install under nvm/fnm is found with its `node`.
- **VPN guard:** apps are never left paused while the Mac is offline or asleep; a network that keeps changing shows a card instead of a silent pause; terminal agents that use a proxy are not paused for nothing; Antigravity is not blocked if Cooldown is removed; settings files that are symlinks keep their link and permissions.
- **Continue:** the button continues the chat named on the card, never whichever chat is open; an old notification no longer sends anything; no "limit is back" while the weekly limit is still spent; a failed send keeps its button.
- **Codex:** auto-continue no longer switches itself off at the moment the limit comes back, stops for a deleted conversation, survives a damaged state file and a Codex app update, and does not open Codex at launch while the limit is still spent; the Codex CLI is found wherever the app is.
- **Updates:** a beta on offer is dropped when betas are turned off; a Cooldown run from the disk image or Downloads says to move it to Applications; an update that cannot go in says why, once; an update waiting more than a day shows a card.
- **Statistics:** "no history yet" is shown only when there is none; Claude Desktop's own history is taken in on the first day.

### Install
`brew install --cask vitalyor/tap/cooldown`, or download **Cooldown-1.4.6.dmg** and drag it to Applications.
On an earlier version? Cooldown updates itself (Settings → Updates).

### Русский

Всё из бета-версий 1.4.6 — теперь для всех.

**Защита VPN**
- **Моргание VPN ловится в ту же секунду.** Cooldown слушает системные сообщения о маршрутах и настройки прокси: туннель пропал на долю секунды, сменился Wi-Fi, включили или выключили прокси — приложения агентов встают на паузу до повторной проверки (обычно меньше секунды).
- **Сон и пробуждение.** После пробуждения приложения сначала на паузе и продолжают после первой проверки, когда VPN вернулся.
- **По два адреса на сервис** (`api.anthropic.com` и `claude.ai`, `chatgpt.com` и `api.openai.com`); считается худший, поэтому ловятся правила VPN «по сайтам».
- **У Antigravity тоже есть хук** (`~/.gemini/config/hooks.json`, чужие записи сохраняются): пока маршрут до Google неправильный, ход заканчивается сообщением, а не запросом к модели.
- **Защита для каждого агента отдельно:** у каждого свой переключатель в «Настройки → Защита VPN»; выключенного агента защита не проверяет, не ставит на паузу, а его хук всё пропускает.
- **Агенты в Терминале (по желанию):** Claude Code, Codex и Antigravity CLI в терминале тоже замирают, даже посреди ответа, и продолжают с того же места.
- **Часовой пояс:** если пояс Mac выдаёт VPN, в настройках есть «Поставить пояс …» и «Вернуть мой пояс» (macOS спросит пароль администратора). Карточка об этом показывается один раз для каждой страны, её можно отложить на час или на день или выключить в настройках.
- Быстрее возвращается к работе (пока маршрут неправильный, проверка раз в 5 секунд первую минуту), не обновляется, пока защита что-то держит, пауза вручную держится свой час, даже если Cooldown закрыт, проверки в хуках идут параллельно (не дольше 3 секунд).

**Лимиты**
- **Лимиты Claude надёжно читаются с новым Claude Code.** Claude Code 2.1.30x сначала показывает прошлые цифры и «Refreshing…», пока не ответит сервер; при медленной связи Cooldown сдавался слишком рано и писал «Не удалось прочитать экран /usage» — у некоторых каждый раз. Теперь он ждёт ответа (до 15 секунд), а если ответа нет, пишет, что повторит через минуту.
- Если исчерпан недельный лимит, «снова можно работать» показывает недельный сброс; состояние «исчерпан» не прыгает; цифры не откатываются к старым; одно окно Claude не считается в статистике дважды; история не перезаписывается каждую минуту.
- Зависшее чтение Codex или Antigravity больше не останавливает обновления этого агента; в строке меню прочерк вместо цифр многочасовой давности.

**Агенты и карточки**
- Автопродолжение Claude не крутится в цикле, пока исчерпан недельный лимит, и продолжает тот чат, который лимит действительно остановил.
- Ответ на вопрос Codex не уходит дважды; хуки Cooldown в Codex не лишают доверия хуки других программ; хранятся только три последние копии настроек.
- Карточки, на которые уже ответили в окне агента, не всплывают позже; карточки слушаются тихих часов; нет лишнего звука на каждую карточку.
- **С телефона:** «Проверить сейчас» и «Включить снова» на карточках защиты, «Отложить» на карточке о часовом поясе, «Обновить» на карточке о новой версии (по Face ID); ответ текстом — по Face ID; ответ всегда попадает в тот вопрос, к которому был дан.

**Настройки**
- **Бета-версии** («Настройки → Обновления»): новое раньше всех. По умолчанию выключено.
- **Отчёт для разработчика** («Настройки → Диагностика → Сохранить…»): один текстовый файл с проверками, версиями программ, настройками, лимитами и последними записями журнала; названия чатов, IP-адреса, почта и имя пользователя из него убраны. Никуда не отправляется: пришлите его сами, если что-то не работает.
- Страница Antigravity; «Что нового» показывается с оформлением на языке приложения; примеры карточек можно остановить; адреса выхода в защите VPN — одна строка на адрес; настройка больше не говорит, что нужны и Claude Code, и Codex.

**Надёжность (полная проверка перед выпуском)**
- **Лимиты Claude:** правильно читаются при первом запуске («Loading usage data…»), на медленной связи (до 40 секунд), на Pro без начатой сессии, со сбросом в следующем году и при ответе Claude Code «rate limited»; цифры, которые Claude Code не смог обновить, больше не принимаются за свежие; ваши MCP-серверы не запускаются ради каждого чтения; Claude Code, поставленный через npm под nvm/fnm, находится вместе со своим `node`.
- **Защита VPN:** приложения не остаются на паузе, пока Mac без сети или спит; если сеть меняется без конца, появляется карточка вместо тихой паузы; агенты в Терминале, работающие через прокси, не замирают зря; Antigravity не блокируется, если Cooldown удалён; файлы настроек-ссылки сохраняют ссылку и права.
- **Продолжить:** кнопка продолжает чат, названный на карточке, а не тот, что открыт сейчас; старое уведомление больше ничего не отправит; нет «лимит восстановился», пока исчерпана неделя; после неудачной отправки кнопка остаётся.
- **Codex:** автопродолжение больше не выключается в момент сброса лимита, останавливается для удалённого диалога, переживает повреждённый файл состояния и обновление приложения Codex и не открывает Codex при запуске, пока лимит ещё исчерпан; Codex CLI находится, где бы ни лежало приложение.
- **Обновления:** предложенная бета снимается, если бета-версии выключены; Cooldown, запущенный с образа диска или из «Загрузок», просит перенести его в «Программы»; если обновление не встаёт, причина говорится один раз; обновление, которое ждёт больше суток, показывает карточку.
- **Статистика:** «истории пока нет» — только когда её правда нет; собственная история Claude Desktop подхватывается в первый же день.

**Установка**
`brew install --cask vitalyor/tap/cooldown` или скачайте **Cooldown-1.4.6.dmg** и перетащите в «Программы».
Стоит более ранняя версия? Cooldown обновится сам («Настройки → Обновления»).
