**Beta.** A preview for testing; it reaches only Macs with Settings → Updates → Beta versions turned on.

### Fixed
- **Claude Code that was never started.** A freshly installed Claude Code shows its first-run setup (text style, sign-in) instead of the limits, and Cooldown waited almost a minute before saying "Couldn't read the /usage screen". It now sees that screen at once, says what is wrong, and the Claude tab has **Open in Terminal** (Claude Code's setup, step by step) and **Check again**. Diagnostics gives the same advice.

### Changed
- **Updates** is now second from the bottom in Settings, above "About Cooldown".

### Русский

**Бета.** Предварительная версия для проверки; её получают только Mac с включёнными «Настройки → Обновления → Бета-версии».

**Исправлено**
- **Claude Code, который ни разу не запускали.** Только что установленный Claude Code вместо лимитов показывает первую настройку (тема, вход), и Cooldown почти минуту ждал, а потом писал «Не удалось прочитать экран /usage». Теперь он сразу узнаёт этот экран и говорит, в чём дело, а на вкладке Claude есть кнопки **«Открыть в Терминале»** (первая настройка Claude Code по шагам) и **«Проверить снова»**. Диагностика советует то же.

**Изменено**
- **«Обновления»** в настройках теперь второй пункт снизу, над «О Cooldown».
