**Beta.** A preview for testing; it reaches only Macs with Settings → Updates → Beta versions turned on.

### Fixed
- **Claude Code signed in with an API key.** Claude Code signed in through Anthropic Console (pay per request) has no 5-hour or weekly limits, and Cooldown said only "Couldn't read the /usage screen". It now says what it is, in a card on the Claude tab: why there is nothing to show, three steps, **Sign in with subscription** (Terminal signs Claude Code out of the key and opens the browser for your Claude account) and **Check again**. Without a Pro or Max subscription there are no Claude limits at all, and the card says that this is not an error.
- **Claude Code that was never started** gets the same kind of card: why, three steps, **Open in Terminal** and **Check again**.

### Русский

**Бета.** Предварительная версия для проверки; её получают только Mac с включёнными «Настройки → Обновления → Бета-версии».

**Исправлено**
- **Claude Code вошёл по API-ключу.** Если Claude Code вошёл через Anthropic Console (оплата за каждый запрос), у него нет лимитов на 5 часов и неделю, а Cooldown писал только «Не удалось прочитать экран /usage». Теперь на вкладке Claude карточка: почему показывать нечего, три шага, кнопки **«Войти через подписку»** (Терминал выводит Claude Code из входа по ключу и открывает браузер для вашего аккаунта Claude) и **«Проверить снова»**. Без подписки Pro или Max лимитов у Claude нет вовсе — карточка говорит, что это не ошибка.
- **Claude Code, который ни разу не запускали,** получил такую же карточку: почему, три шага, **«Открыть в Терминале»** и **«Проверить снова»**.
