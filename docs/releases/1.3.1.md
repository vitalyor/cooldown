**English** · [Русский](#русский)

### What's new
- **Signed and notarized by Apple.** Cooldown is now signed with a Developer ID certificate and checked by Apple, so it opens like any other Mac app — no "unverified developer" warning, no trip to Privacy & Security.

### Good to know
- Because the signature changed, macOS asks once more for **Accessibility** (and may ask about notifications). Grant it in System Settings → Privacy & Security → Accessibility; if Cooldown is already listed there, remove it with “−” and add it again.

### Install
`brew install --cask vitalyor/tap/cooldown`, or download **Cooldown-1.3.1.dmg** and drag it to Applications.
On 1.3.0? Cooldown updates itself (Settings → Updates). On 1.2.x or earlier, install 1.3.1 once by hand (Homebrew or the .dmg): the old updater only accepts its old signature.

### Русский

**Что нового**
- **Подписано и заверено Apple.** Cooldown теперь подписан сертификатом Developer ID и проверен Apple — открывается как любое приложение для Mac, без предупреждения о «непроверенном разработчике» и без похода в «Конфиденциальность и безопасность».

**Стоит знать**
- Подпись сменилась, поэтому macOS ещё один раз попросит **Универсальный доступ** (и, возможно, уведомления). Включите его в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ»; если Cooldown там уже есть, удалите запись кнопкой «−» и добавьте снова.

**Установка**
`brew install --cask vitalyor/tap/cooldown` или скачайте **Cooldown-1.3.1.dmg** и перетащите в «Программы».
Стоит 1.3.0? Cooldown обновится сам («Настройки → Обновления»). Стоит 1.2.x или старше — один раз поставьте 1.3.1 вручную (через Homebrew или .dmg): старое обновление принимает только прежнюю подпись.
