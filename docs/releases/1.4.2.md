**English** · [Русский](#русский)

### What's new
- **Pick any one or two lines for the menu bar.** Settings → Menu Bar → "Lines in the menu bar": Codex, Claude and Antigravity, any one or two of them, for example Codex and Antigravity. Your earlier choice is kept.

### Install
`brew install --cask vitalyor/tap/cooldown`, or download **Cooldown-1.4.2.dmg** and drag it to Applications.
On an earlier version? Cooldown updates itself (Settings → Updates).

### Русский

**Что нового**
- **Любые одна или две линии в строке меню.** «Настройки → Строка меню → Линии в строке меню»: Codex, Claude и Antigravity, любые одна или две, например Codex и Antigravity. Прежний выбор сохраняется.

**Установка**
`brew install --cask vitalyor/tap/cooldown` или скачайте **Cooldown-1.4.2.dmg** и перетащите в «Программы».
Стоит более ранняя версия? Cooldown обновится сам («Настройки → Обновления»).
