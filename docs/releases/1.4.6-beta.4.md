**Beta.** A preview for testing; it reaches only Macs with Settings → Updates → Beta versions turned on.

### Fixed
- **The time zone card no longer comes back on every VPN move.** It was shown again each time the VPN switched
  to a server in another country; now it is said once per country, and "Remind me in an hour" / "Remind me
  tomorrow" put it off. Settings → VPN guard → "Remind about the time zone" turns the card off (the note in
  Settings stays). On the phone the card stays in the app, without an alert.
- **Guard cards show all they say:** a card that waits for an answer has room for six lines.
- "Antigravity sees Russia" now reads right in Russian.

### Русский

**Бета.** Предварительная версия для проверки; её получают только Mac с включёнными «Настройки → Обновления → Бета-версии».

**Исправлено**
- **Карточка о часовом поясе больше не возвращается при каждом переключении VPN.** Раньше она появлялась снова,
  стоило VPN перейти на сервер в другой стране; теперь — один раз для каждой страны, а «Отложить на час» /
  «Отложить на день» её откладывают. «Настройки → Защита VPN → Напоминать о часовом поясе» выключает карточку
  (пометка в настройках остаётся). На телефоне карточка остаётся в приложении, без уведомления.
- **Карточки защиты показывают всё, что говорят:** у карточки, ждущей ответа, место на шесть строк.
- «Antigravity видит страну «Россия»» вместо «видит Россия».
