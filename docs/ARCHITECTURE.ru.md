# Устройство Cooldown

[English](ARCHITECTURE.md) · **Русский**

Swift Package, SwiftUI + AppKit, без сторонних зависимостей. Окно — стеклянная панель
(`NSGlassEffectView`) под значком в строке меню.

## Модули

| Папка | Что внутри |
|---|---|
| `Core/` | `AppModel` (состояние, таймеры), `AgentActivity` (кто работает, ждёт, закончил), хранилища (`HistoryStore`, `DailyLog`, `TurnLog`, `EventLog`), прогноз и темп, хуки, наблюдение за файлами |
| `Codex/` | лимиты через `codex app-server`, история из файлов сессий, индекс разговоров (`state_*.sqlite`), наблюдатель окончания работы, отложенные задачи |
| `Claude/` | лимиты (`/usage`, строка статуса, Claude Desktop), окно Claude Desktop через Accessibility, сессии Claude Code |
| `AutoResume/` | автопродолжение Codex: локальный сокет приложения (только как наблюдатель), правила решения, журнал отправок, наблюдение за задачей |
| `UI/` | панель, вкладки, карточки, настройки, значок в строке меню |
| `Core/PhoneLink*` | связь с iPhone на стороне Mac: карточки и состояние туда, команды оттуда (см. [LINK.ru.md](LINK.ru.md)) |
| `Core/CodexLink`, `Core/AgentRestart` | как Cooldown замечает, что Codex перестал ему отвечать; безопасный перезапуск Codex и Claude |
| `Core/RouteGuard`, `Core/NetWatch` | защита VPN: проверка маршрута каждого сервиса, события сети, заморозка приложений (`Freezer`), файлы для хуков, часовой пояс |
| `Core/AntigravityLimits` | лимиты Antigravity из его собственной команды `agy /usage` |
| `Sources/CooldownLink/` | сквозное шифрование связи, общее для Mac и iPhone |

## Один координатор событий

Все источники сообщают в `AgentActivity`: файлы сессий Codex, хуки, окно Claude Desktop.
Он решает, что показать: один и тот же конец работы, увиденный двумя источниками, объявляется один раз;
короткие ходы не объявляются; длительность и доля лимита считаются от начала хода.

## Лимиты Claude

Несколько источников сводятся одним правилом (`ClaudeLimits.merge`): для каждого окна берётся текущее
(самое позднее время сброса), среди показаний этого окна — наибольшее (внутри окна расход только растёт).
Показания, отставшие больше чем на 20 минут от самого свежего, не учитываются.

## Защита VPN

`RouteGuard` спрашивает каждый сервис, откуда к нему приходит запрос по его маршруту: `/cdn-cgi/trace` самого
Cloudflare на `api.anthropic.com`, `claude.ai`, `chatgpt.com` и `api.openai.com`; для Antigravity — служебные
данные YouTube, запрошенные через `curl --connect-to` на `cloudcode-pa.googleapis.com`, то есть по маршруту
самого Antigravity. Отдельно IPv4 и IPv6 и через системный прокси, если он задан; считается худший ответ.

- **Когда.** Раз в 5 секунд, пока агент работает или его приложение на экране, иначе раз в 15; в первую
  минуту неполадки — раз в 5. Google — не чаще раза в 15 секунд, пока открыт Antigravity, и раз в минуту иначе
  (частые анонимные запросы он принимает за робота). Сразу после смены сети: `NetWatch` читает системный
  канал маршрутов и настройки прокси SystemConfiguration, а «отпечаток» сети (адреса интерфейсов, основные
  маршруты, прокси) отличает настоящую смену от шума.
- **Как держит.** Неправильный ответ или два ответа подряд не пришли — Cooldown не делает своих запросов
  (`RouteGuard.gate`) и держит агентов: хуки в Claude Code (`UserPromptSubmit`, `PostToolBatch`), Codex
  (`UserPromptSubmit`) и Antigravity (`PreInvocation` в `~/.gemini/config/hooks.json`) читают файлы защиты
  и проверяют маршрут сами, если ответа Cooldown нет или он старый. `Freezer` ставит приложения на паузу
  сигналом SIGSTOP и отпускает SIGCONT; агентов в терминале — по желанию, придержав сначала их оболочку,
  чтобы агент остался на переднем плане.
- **Успокоение.** После смены сети или пробуждения приложения на паузе до следующей проверки (обычно меньше
  секунды); если проверка не отвечает, карточка появится только через 15 секунд. Перед сном ничего не
  замораживается (остановленное приложение задерживало бы сон).
- **Безопасно в обе стороны.** Сторожевая оболочка в отдельной сессии отпускает всё через две секунды, если
  Cooldown упал; пауза записывает своё окончание в файлы для хуков, поэтому заканчивается и при закрытом Cooldown.
- **Тесты.** `Cooldown --guard-test <home> <dummy.app>` гоняет защиту целиком на выдуманных ответах и
  одноразовом приложении; `--guard-test-terminal`, `--guard-test … --tree` и `--guard-hooks-test` (на копиях
  настроек агентов) проверяют остальное.

## Бережём ресурсы

- **События вместо опроса.** Папки сессий — через FSEvents; файл хуков — через dispatch source
  (`Core/FileWatch.swift`). Таймеры остаются только страховкой и запускаются с допуском, чтобы macOS
  объединяла пробуждения.
- **Внешние программы — по необходимости.** Пока Codex работает, лимиты приходят из его файлов,
  `codex app-server` не запускается. `claude /usage` идёт за Claude: раз в минуту, пока он работает,
  потом пауза растёт на полминуты за каждую тихую минуту, до пяти; через полчаса тишины — раз в
  15 минут (30 при заблокированном экране), около сброса — раз в 2 минуты, и вовсе не запускается,
  пока строка статуса Claude Code приносит свежие цифры.
- **Автопродолжение реагирует, а не опрашивает.** Задача проверяется, когда её файл сессии сообщает о
  завершённом или сорванном раунде, по хукам Codex, при запуске и закрытии приложения Codex и после
  пробуждения Mac; пока ждёт лимита — таймер по настенным часам срабатывает точно в момент сброса
  (+15 с). Редкая контрольная проверка ловит только то, о чём не пришло событие. Всё внутри Cooldown,
  без лишних процессов; `codex app-server` запускается лишь чтобы прочитать лимиты в этот момент.
- **Окно Claude Desktop.** Обычно читается только адрес чата и поле ввода (десятки элементов, один
  запрос на элемент); всё окно — когда что-то поменялось или раз в минуту. Всё вне главного потока.
- **Отрисовка.** Свет на линии в строке меню — анимация Core Animation, картинка не перерисовывается.
  Значок строки меню и частые «признаки жизни» агентов не вызывают перерисовку окна.
  Скрытое окно ничего не опрашивает.
- **История** читается кусками по мере дописывания файлов; курсоры переживают перенос файлов Codex
  между папками.

## Диагностика

```sh
Cooldown --claude-usage            # что читается из /usage
Cooldown --hooks status            # состояние хуков (install / uninstall)
Cooldown --menu-icon out.png       # значок строки меню в разных состояниях
Cooldown --render --out out.png --provider codex --tab stats   # окно в картинку
Cooldown --showcase --demo 1 --tab limits --clean   # настоящее окно на демо-данных, для скриншотов
Cooldown --snapshot out.png --tab tasks --provider claude   # настоящее окно на сохранённых данных, как на экране
Cooldown --settings-snapshot vpn out.png --height 760   # раздел настроек на выдуманных данных, нарисованный за экраном
Cooldown --render --dark --cards guard,exit,request,paused --out out.png   # карточки столбиком (картинки для README)
Cooldown --render --card request --dark   # одна карточка; --render --menu — картинка строки меню
Cooldown --selftest                       # встроенные проверки
scripts/check-all.sh                      # сборка, самопроверка и тесты
scripts/icon-preview.sh                   # все варианты иконки
scripts/readme-shots.sh                   # картинки README за экраном, на английском и русском
```

Что делали источники и почему была или не была показана карточка — в
`~/Library/Application Support/Cooldown/activity.log`.

## Локализация

Строки интерфейса пишутся в коде по-русски и оборачиваются в `L("…")`; русский текст и есть ключ.
`L(ключ, аргументы…)` подставляет `%@` в языке приложения. Слова с числами — ключи вида
`"один|два|пять"`; в переводе столько форм, сколько нужно языку, нужную выбирает `AppLanguage.pluralIndex`.

Переводы лежат в `Resources/Localization/src/<язык>.json` (ключ → текст). Чтобы добавить или поменять строки:

```sh
python3 scripts/l10n_wrap.py keys     # все ключи из кода
python3 scripts/l10n_build.py         # проверить полноту, подстановки и формы чисел, собрать *.lproj
```

Перед релизом `l10n_build.py` должен показать `problems: 0`. `build.sh` кладёт папки `.lproj` в приложение.
Проверить язык, не переключая macOS: `Cooldown --settings-window general -AppleLanguages '(de)'`.
