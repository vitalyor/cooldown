# Что Cooldown читает и куда обращается

[English](PRIVACY.md) · **Русский**

Cooldown работает на вашем Mac. Аналитики и телеметрии нет. К relay он обращается только если вы включили Cooldown для iPhone, а к GitHub — за обновлениями, если это не выключено.

## Читает (только чтение)

| Что | Зачем |
|---|---|
| `~/.codex/sessions`, `~/.codex/archived_sessions` | токены, лимиты, начало и конец работы Codex |
| `~/.codex/state_*.sqlite` (только чтение) | список разговоров Codex и где лежат их файлы |
| `~/.codex/session_index.jsonl` | названия разговоров |
| `~/.claude/projects` | токены Claude Code |
| `~/Library/Application Support/Claude/plan-usage-history.json` | история лимитов, которую ведёт Claude Desktop |
| `~/Library/Application Support/Claude/claude-code-sessions` | названия сессий Claude Code из Claude Desktop |
| Окно Claude Desktop через «Универсальный доступ» | какой чат открыт, пишет ли Claude ответ, первые слова ответа |

## Запускает

- `codex app-server` — запрос лимитов `account/rateLimits/read` (официальный клиент Codex); для автопродолжения ещё `thread/list` и `thread/read` — только чтение.
- `claude /usage` — экран лимитов Claude Code (официальный клиент). Хуки, строка статуса и фоновый
  трафик Claude Code для этого запуска выключены.
- `agy -p /usage` — экран лимитов Antigravity (его собственная командная строка), локально: без запроса к модели и без расхода квоты.
- `codex exec` — только задачи, которые вы сами отложили.
- С включённой защитой VPN: `curl` для проверок маршрута (ниже); `/bin/sh` для сторожа, который отпускает
  приложения, если Cooldown остановился; `osascript`, чтобы сменить часовой пояс, — только по нажатию этой кнопки.

## Меняет (только с вашего согласия)

- `~/.claude/settings.json` — строка статуса и хуки Cooldown, если вы их включили. Перед записью
  рядом сохраняется копия. Чужие записи (например, Coucou) не трогаются.
- `~/.codex/hooks.json` — хуки Cooldown, если вы их включили. Codex попросит их разрешить.
- `~/Library/Application Support/Claude/claude_desktop_config.json` — необязательный локальный
  MCP-мост, только если вы включили его в настройках. Чужие MCP-серверы Claude сохраняются,
  перед записью рядом кладётся копия.
- Хуки защиты VPN («Настройки → Защита VPN», по умолчанию выключена) в тех же двух файлах, отдельными
  записями, и в `~/.gemini/config/hooks.json` Antigravity (запись `cooldown-guard`; перед записью рядом
  кладётся копия, чужие записи сохраняются). Это единственные хуки Cooldown, которые могут остановить агента:
  сообщение не уходит или работа останавливается между шагами, пока маршрут к сервису идёт мимо VPN.
  Выключение защиты их убирает; если выключить её для одного агента, его хук всё пропускает; если удалить
  Cooldown, они не найдут скрипт и всё пропустят.
- Часовой пояс Mac — только когда вы нажали «Поставить пояс …» в «Настройки → Защита VPN», с паролем
  администратора, который спросит macOS. Автоматический выбор пояса на это время выключается; «Вернуть мой
  пояс» ставит ваш и включает его обратно.
- Из копий каждого изменённого Cooldown файла настроек хранятся только три последние.

Исключение — хук разрешений Claude Code: пока вы не в приложении, где идёт эта сессия, он ждёт
ответа, нажатого на карточке Cooldown (до часа), и передаёт его; в том приложении или без запущенного
Cooldown он сразу выходит, и Claude Code спрашивает как обычно.

Хук Cooldown только дописывает одну строку в
`~/Library/Application Support/Cooldown/hook-events.jsonl` и сразу выходит. Файл ротируется на 8 МБ.
MCP-мост дописывает только те события, которые Claude решил передать, в `mcp-events.jsonl`.

## Отправляет

- С включённой защитой VPN — анонимный запрос к `/cdn-cgi/trace` адресов `api.anthropic.com`, `claude.ai`,
  `chatgpt.com` и `api.openai.com` (отдельно по IPv4 и IPv6 и через системный прокси, если он задан)
  раз в 5–15 секунд и при смене сети; пока маршрут неправильный — раз в 5 секунд первую минуту, потом раз в 15. Cloudflare
  перед этими сервисами отвечает, какую страну и какой адрес он видит. Для Antigravity — взгляд самого
  Google: анонимный запрос `https://www.youtube.com/sw.js_data`, отправленный на адрес API Antigravity
  `cloudcode-pa.googleapis.com`, раз в 15 секунд, пока Antigravity открыт, и раз в минуту иначе
  (частые запросы Google принимает за робота). Это обычный запрос `curl`:
  без аккаунта, cookies, токенов и названия приложения; своего сервера для этого у Cooldown нет. Пока маршрут неправильный,
  а также на время проверки после смены сети или пробуждения Mac, Cooldown ставит приложения агентов на паузу (SIGSTOP),
  если вы это разрешили (и Claude Code, Codex и Antigravity CLI в Терминале, если разрешили и это), и снимает её (SIGCONT),
  когда маршрут в норме. Смену сети Cooldown замечает по системным сообщениям о маршрутах и настройкам прокси на этом Mac;
  никуда это не отправляется.

- Ответы на запросы агентов (разрешения, вопросы) — **только кнопка, нажатая вами на карточке**: в Codex через команды приложения для его окон, в Claude Code через хук разрешений, в чат Claude Desktop нажатием той же кнопки в чате. Перед отправкой Cooldown проверяет, что висит тот же самый запрос.
- В выбранный вами диалог Codex — одно сообщение-продолжение на каждый раунд, остановленный лимитом, после его сброса. Через локальный сокет приложения Codex (`~/.codex/ipc/ipc.sock`), только как наблюдатель: Cooldown не одобряет действия и не отвечает на запросы приложения. Журнал отправок — `~/Library/Application Support/Cooldown/AutoResume/` (только для вас); неподтверждённая отправка никогда не повторяется.

- На ваш iPhone — только если вы включили Cooldown для iPhone и подключили телефон: карточки,
  названия чатов, ответы и журнал доставки шифруются на Mac и открываются только на вашем телефоне;
  сервер-посредник Cooldown передаёт их, не читая. Для Live Activity он
  видит общие строки («Claude работает»), подписи кнопок и время сброса. Подробно: [LINK.ru.md](LINK.ru.md).

Вход Claude Code (токен из Связки ключей) Cooldown не использует: Anthropic разрешает его только
в собственных приложениях.

## Сервер-посредник и приложение для iPhone

Сервер хранит только то, что нужно для передачи сообщений: идентификатор и имя каждого сопряжённого устройства
(имя вашего Mac или телефона), хеш токена доступа, push-токены Apple, время последнего подключения и запечатанные
сообщения для устройства не на связи (не дольше суток). Отключение удаляет устройство и всё, что его ждёт;
сопряжение, которым не пользовались 180 дней, удаляется. IP-адреса используются для ограничения частоты запросов
и не хранятся вместе с сопряжением. В приложении для iPhone нет аккаунта, аналитики и рекламы. Чтобы удалить данные,
отключите телефон или напишите разработчику через страницу проекта на GitHub.

## Хранит

Всё в `~/Library/Application Support/Cooldown/`: история лимитов и токенов (45 дней), итоги по дням,
события, выбранные чаты, записи для диагностики (`activity.log`, до 2 МБ в двух файлах; если
подключён iPhone — ещё `phone-delivery.log`: только время и id, без текста).
